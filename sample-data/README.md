# MelaReady Sample Demonstration Data

This folder contains `fictional_demo.json`, an illustrative dataset showcasing the structure of events, members, tasks, reports, and location snapshots handled by MelaReady.

## Important Privacy & Runtime Notes

1. **Fictional Data Only**: All names (`Asha Demo`, `Ravi Demo`), emails (`@example.test`), phone numbers (`+91 98000 00001`), and coordinates (`30.37520, 76.78210`) are purely fictional placeholder values for demonstration and hackathon review.
2. **Server Runtime Storage**: The Python backend (`server/server.py`) generates its own SQLite database (`melaready_demo.sqlite3`) at runtime when started. This JSON file is provided for documentation and mock testing reference only.
3. **No Secrets**: No real user credentials, passwords, session tokens, or private audio files are contained in this repository.
