# MelaReady v0.3 — Android Studio source

Backend, login, permissions aur two-device setup ke liye `START_V3_HINGLISH.md` padho.

Naam: **MelaReady**. Matlab: mela ya gathering se pehle taiyaar team.

## Sabse pehle

1. ZIP extract karo. Existing app ke andar files paste mat karo; alag folder rakho.
2. Android Studio → Open → `MelaReady` folder select karo.
3. Gradle JDK 17 select karo. SDK 36 aur Build Tools 36.0.0 install karne ka prompt aaye to install karo.
4. Sync complete hone do. Phone/emulator select karke Run dabao.
5. APK se seedha trial karna ho to pack ke `APK` folder mein debug APK hai. Pehle apne test phone par use karo.

## 3-minute demo

1. Home → **Explore a fictional sample**. Bolo: “Yeh fictional venue aur local prototype hai.”
2. Team → Add. Naam, role aur zone add karo. Yeh local entry hai; invitation nahi bhejta.
3. Practice → teen decisions complete karo. Ek galat answer select karke feedback bhi dikhao.
4. Home → Check the essentials. Checklist ka progress dekho.
5. Home → Open the drill log. Ek drill observation add karo; acknowledgement, assignment aur resolution simulate karo.
6. Map → fictional sketch aur device location snapshot ko alag samjhao. Location permission user ke button tap par aayegi.
7. App dobara kholkar event aur drill progress persistence check karo. GPS snapshot intentionally permanent storage mein nahi hai.
