## Reporting Vulnerabilities

If you discover a security vulnerability in MelaReady, please report it responsibly by contacting the maintainers privately rather than opening a public issue.

**Email**: `anurag@tripathitechnologies.com`

Please include:
- A description of the issue.
- Steps to reproduce or proof-of-concept.
- Potential impact.

We will acknowledge receipt of your report within 48 hours and work on a resolution promptly.

---

## Important Security & Privacy Notice

1. **Prototype Disclaimer**: MelaReady is an open-source demonstration prototype for local preparation and drill practice. It is **not** a production emergency-response system and is not connected to government dispatch centers.
2. **Public Issue Privacy**: **NEVER** post session tokens, passwords, database dumps, real phone numbers, actual GPS coordinates, or private audio files in public GitHub issues or discussions.
3. **Local Pilot Deployment**: When running the demo Python server on a local network, deploy only on a trusted Wi-Fi network. Production deployment requires HTTPS, reverse-proxy configuration, and secure credential handling.
